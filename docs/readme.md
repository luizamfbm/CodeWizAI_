# CodeWiz Assistant

CodeWiz Assistant is an intelligent Q&A system for the CodeWiz team and franchisees.  
It answers questions strictly based on internal documentation, avoiding hallucinations and enforcing guardrails.

Demo Video: see demo/DemoCodeWizAI.mp4 for a complete walkthrough of the assistant.

## What does this system do?

- **Document Ingestion:** Collects internal documents (PDFs, Google Docs exported as PDFs, etc.) from Google Drive and stores them in a single local folder (`data/raw`).
- **Preprocessing:** Extracts metadata, performs OCR on image-based PDFs, splits documents into chunks, classifies each chunk by topic (bucket), and redacts sensitive information (emails, phone numbers, names, IDs).
- **Deduplication:** Removes redundant or highly similar chunks, prioritizing the most recent and highest-quality content.
- **Embedding Generation:** Converts each chunk into a semantic vector using OpenAI’s `text-embedding-3-large` model.
- **Vector Storage:** Stores embeddings in a local FAISS vector database for fast and accurate retrieval.
- **Retrieval and Answer Generation:** When a user asks a question, retrieves the most relevant chunks and uses GPT-4 Turbo to generate an answer based only on these, adapting tone and detail to the user’s persona (franchisee, support/technical team, or management/leadership).
- **User Interface:** Streamlit web interface for persona selection, question input, and answer display. Internal users can see which document chunks and sources were used.
- **Logging & Analytics:** Logs all Q&A to CSV for later analysis. A Streamlit dashboard shows the most common and unanswered questions by persona.
- **Data Inventory:** Automatically generates a CSV inventory of all processed documents, including topics (buckets) and applied transformations.
- **Scalability:** Local-first architecture, but ready for cloud migration and automated ingestion.

## Google Drive Sync (via Apps Script)

Before running the local ingestion pipeline, use the provided Google Apps Script to automate weekly export of documents from Google Drive.

**How it works:**
- Monitors a source folder with Google Docs, Sheets, or Slides
- Converts new/modified files to PDF
- Saves PDFs to a target Drive folder
- Optionally moves orphaned PDFs to trash if the source was deleted

**How to run:**
1. Go to https://script.google.com
2. Paste the contents of `google-apps-script.js`
3. Update `SOURCE_FOLDER_ID` and `TARGET_FOLDER_ID`
4. Click Run and authorize permissions
5. (Optional) Set a weekly trigger for automated sync


## Downloading Local PDFs

After exporting to the target folder, download the PDFs locally:

```sh
gdown --folder https://drive.google.com/drive/folders/<FOLDER_ID> -O data/raw
```
Replace `<FOLDER_ID>` with your Google Drive target folder ID.


## System Installation

1. **Clone this repository or unzip the provided folder.**

2. **(Recommended) Create a Python virtual environment:**
    ```sh
    python3 -m venv venv
    source venv/bin/activate
    ```

3. **Install the requirements:**
    ```sh
    pip install -r requirements.txt
    ```

4. **Set your environment variable for OpenAI:**
    ```sh
    export OPENAI_API_KEY="your_api_key_here"
    ```

5. **Run the ingestion pipeline to build the vector store:**
    ```sh
    python3 scripts/main.py
    ```

6. **Start the Streamlit interface:**
    ```sh
    streamlit run scripts/interface.py
    ```


## Docker

If you prefer Docker: 

1. Make sure you have Docker and Docker Compose installed and running.
2. Set your OpenAI API key as an environment variable:
   export OPENAI_API_KEY=sk-xxxx
3. In the project root, run:
   docker-compose up --build
4. Access the assistant at http://localhost:8501 and the dashboard at http://localhost:8502
